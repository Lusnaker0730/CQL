  1. 資料庫 (Database)                                                                                                                              
  目前開發用 H2 記憶體資料庫，正式環境用 PostgreSQL。已有 Flyway                                                                                 
  做版本遷移。缺少：連線池調優（HikariCP）、資料庫高可用（主從備援）、定期備份機制。

  2. 身份驗證 (Authentication)

  已有 JWT Token + BCrypt 密碼加密。缺少：密碼強度規則（最少幾碼、要求大小寫等）、強制 HTTPS、Token 刷新機制、帳號鎖定（多次登入失敗）。

  3. 錯誤處理 (Error Handling)

  已有 GlobalExceptionHandler 統一處理例外。缺少：更細緻的自訂例外類型、前端全域錯誤通知機制的完善。

  4. 測試覆蓋率 (Testing)

  後端約 34 個測試、前端約 14 個測試，覆蓋率偏低。需要：大幅增加單元測試和整合測試，目標至少 70-80% 覆蓋率。

  5. API 文件 (API Documentation)

  已啟用 Swagger，但缺乏詳細的 @ApiOperation、@ApiParam 等註解。需要：為每個 API 端點加上說明，方便其他開發者串接。

  6. 效能 (Performance)

  已有 Circuit Breaker（斷路器）模式。缺少：快取策略（Redis 等）、分頁查詢優化、大量指標評估的非同步處理。

  7. 監控 (Monitoring)

  已整合 Prometheus + Grafana 監控架構。需要：調整正式環境的取樣率、增加業務層面的告警規則、日誌集中管理（ELK 等）。

  8. 部署 (Deployment)

  已有 Docker Compose + Kubernetes 設定檔。缺少：K8s Secrets 管理（不能明文存密碼）、正式環境的 CI/CD 流程完善、藍綠部署或滾動更新策略。

  9. 資料驗證 (Data Validation)

  已有 XSS 過濾、欄位加密、SQL 參數化查詢。需要：更完整的輸入驗證（邊界值、格式檢查）、API 層面的 rate limiting（速率限制）。

  10. 合規性 (Compliance)

  已支援 FHIR R4 和 CQL 標準。缺少：HIPAA 合規文件（美國醫療資料保護法）、病患資料去識別化工具、稽核日誌（誰在什麼時候存取了什麼資料）。
